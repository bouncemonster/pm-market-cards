Репозиторий хранит готовые изображения товарных карточек. Это **библиотека визуальных материалов**, а не исходный код интернет-магазина: для просмотра изображений не требуется установка зависимостей или запуск приложения.

Название файла связывает изображение с товаром: числовой идентификатор, читаемое наименование и суффикс `_infographic.jpg` помогают найти нужный материал и не перепутать варианты.

## Как найти нужную карточку

Используйте поиск файлов GitHub по идентификатору товара, бренду или части наименования. Например:

| Поисковый фрагмент | Пример назначения |
| --- | --- |
| `100070300462` | Конкретный товар по идентификатору. |
| `BROVI` | Материалы бренда. |
| `Kwadron` | Карточки соответствующего оборудования или расходных материалов. |
| `_infographic.jpg` | Изображения товарной инфографики. |

Откройте найденный файл, проверьте изображение и точный товарный вариант, затем получите исходный файл через интерфейс GitHub. Для работы со всей библиотекой можно клонировать репозиторий:

```sh
git clone https://github.com/bouncemonster/pm-market-cards.git
cd pm-market-cards
```

Библиотека содержит растровые материалы; полное клонирование не требуется для получения одной карточки.

## Как обновлять материалы

**Сохраняйте соответствие «идентификатор → товар → изображение».** Перед заменой проверьте бренд, наименование, оттенок или модель, объём и вариант упаковки по актуальному источнику товара.

Не переименовывайте и не перемещайте уже используемый файл без проверки внешних ссылок: его путь может использоваться в опубликованных карточках. При замене изображения сохраните читаемость текста, пропорции, отсутствие обрезанных элементов и сопоставимое качество экспорта.

В одном изменении удобно объединять материалы одной товарной группы и описывать, что обновилось. Не добавляйте временные экспорты, дубликаты с неясными именами, персональные данные, служебные токены или непроверенные рекламные обещания.

## Границы использования

Этот репозиторий не является учётной системой цен и остатков, источником инструкций по процедурам или подтверждением свойств продукции. Перед публикацией сверяйте коммерческие и технические сведения с актуальными данными магазина и производителя.

Права на бренды, фотографии, тексты и отдельные материалы сохраняются за соответствующими правообладателями. Публичный доступ к файлам сам по себе не означает разрешения на произвольное коммерческое переиспользование.

## English

**PM Market Product Cards** is a visual asset library of product infographics, not the store's application source. Images are organized through filenames containing a product identifier, a readable product name and the `_infographic.jpg` suffix.

Find an asset by product ID or brand, inspect the exact product variant and download the original image. Preserve published file paths when updating assets, and verify product facts before using an image in a live listing. The repository is not a live source of prices, inventory or clinical instructions. Existing intellectual-property rights remain unchanged.
